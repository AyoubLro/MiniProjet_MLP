# MiniProjet_MLP

## Description
Mini projet de Machine Learning développé en Python dans le cadre d’un projet académique.  
Le projet permet de traiter des données, entraîner un modèle de Machine Learning et effectuer des prédictions avec analyse des résultats.

---

## Technologies utilisées
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib

---

## Fonctionnalités
- Prétraitement des données
- Nettoyage des données
- Analyse des données
- Entraînement du modèle
- Évaluation des performances
- Visualisation des résultats

---

Installation
Cloner le projet
git clone https://github.com/AyoubLro/MiniProjet_MLP.git
Accéder au dossier
cd MiniProjet_MLP

Installer les dépendances
pip install -r requirements.txt

Exécution
python main.py
